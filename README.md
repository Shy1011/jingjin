# 自我精进 · PWA 部署说明

把「自我精进」放到 GitHub Pages 上，变成一个可以从桌面图标启动、没有地址栏和标签页、断网也能打开的应用。

---

## 一、文件说明

上传时要保持这 6 个文件**在同一层目录**：

```
index.html            应用本体（全部代码都在里面）
manifest.json         PWA 说明书：名称、图标、独立窗口模式
sw.js                 Service Worker：离线缓存 + 版本更新
icon-192.png          图标（小）
icon-512.png          图标（大）
apple-touch-icon.png  图标（iOS 用）
```

所有引用都是相对路径（`./xxx`），所以放在 `用户名.github.io/仓库名/` 这种子目录下也能正常工作。

---

## 二、部署到 GitHub Pages

不用装任何工具，网页上点几下就行。

### 1. 建仓库

- 打开 https://github.com/new
- **Repository name** 填一个英文名，例如 `fitness`
  （这个名字会成为网址的一部分，建议用英文，中文名会让网址变成一长串百分号编码）
- 选 **Public**
  （GitHub Pages 免费版只对公开仓库开放；私有仓库需要付费账号）
- 点 **Create repository**

### 2. 上传文件

- 在新仓库页面点 **uploading an existing file**
- 把上面那 6 个文件**全部**拖进去
- 点 **Commit changes**

### 3. 打开 Pages

- 进仓库的 **Settings** → 左侧 **Pages**
- **Source** 选 `Deploy from a branch`
- **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**

### 4. 等一两分钟

刷新 Settings → Pages 页面，顶部会出现网址，形如：

```
https://你的用户名.github.io/fitness/
```

电脑浏览器打开确认能看到「作息」页。

### 5. 装到手机

1. 手机浏览器（Chrome / Via 都行）打开上面这个网址
2. 等页面完全加载（Service Worker 需要几秒完成缓存）
3. 浏览器菜单 → **添加到主屏幕** / **安装应用**
4. 桌面上会出现绿色哑铃图标，点开直接是作息页，没有地址栏

> 页面上那个「一键添加到桌面」横幅，在 https 环境下会自己弹出来，点它也一样。

## 二·五、和本地那份副本的关系

桌面上现在有两份 `index.html`：

- `锻炼/减脂打卡/减脂打卡.html` —— 本地文件版（用手机浏览器直接打开文件用）
- `锻炼/减脂打卡-pwa/index.html` —— 这份，用来上传到 GitHub

**改代码时以一份为准，改完再同步另一份**，否则两边会慢慢跑偏。建议以后只维护 PWA 这份，本地那份留着当离线备份。

---

## 三、以后怎么更新页面

**这一步很重要，漏了的话手机会一直用着旧版本。**

1. 改 `index.html`
2. **把 `sw.js` 里的 `VERSION` 改一下**（例如 `v1` → `v2`）
3. 在 GitHub 仓库里重新上传这两个文件（覆盖）
4. 手机上打开应用**两次**——第一次仍然显示旧版并在后台下载新版，第二次就是新版了

之所以要改 `VERSION`：Service Worker 为了让你秒开，是先给缓存、再偷偷更新。版本号不变，浏览器就认为缓存还是最新的，不会去换。

---

## 四、数据说明

- 打卡记录、体重、记录页数据都存在**你手机自己的浏览器里**（localStorage），**不在 GitHub 上**，也不会上传到任何服务器。
- 所以：**打开就是上次的状态，不需要导入任何东西。** 更新页面代码也不会动你的数据。
- **数据不会跨设备同步**，只在这台手机的这一个浏览器里。
- 会丢数据的情况：卸载这个应用、清除浏览器数据、换手机。重要的话用打卡页「数据管理 → 导出数据」存一份 JSON，需要时再导入。

---

## 五、常见问题

**打开还是旧版本？**
先确认 `sw.js` 里的 `VERSION` 改了并且已上传。还不行就删掉桌面图标、重新添加一次。

**桌面图标还是旧的？**
图标会被系统缓存。删掉图标重新添加，或者重启一次手机。

**国内访问 github.io 很慢或打不开？**
换个托管平台即可，文件结构完全一样，不用改任何代码。可选：Cloudflare Pages（支持私有仓库、免费）、Gitee Pages（需实名认证）。步骤都是「新建项目 → 上传同样的 6 个文件 → 得到 https 网址」。

**装完发现数据是空的？**
正常。这是一台新设备、一个新的网址，等于全新开始。想在旧数据基础上继续，就在旧地址里「导出数据」，到新地址「导入数据」。

**能从手机浏览器直接安装吗？**
可以。Chrome 需要 https（本地 `file://` 不行），这也正是我们要放到 GitHub Pages 上的原因。
